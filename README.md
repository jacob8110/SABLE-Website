# SABLE · Fragrance House

**صفحة هبوط (Landing Page) أنيقة لعلامة SABLE للعطور الفاخرة.** تعرض الصفحة قصة العلامة، مجموعات العطور وتفاصيلها، وتمنح الزائر تجربة تفاعلية تساعده على اكتشاف العطر المناسب.

[زيارة الموقع](https://jacob8110.github.io/SABLE-Website/)

![مشهد عطور SABLE الرئيسي](images/sable-perfume-scene.png)

## مميزات الصفحة

- تصميم متجاوب مع الشاشات المختلفة.
- أقسام للتعريف بالعلامة، المجموعات، والعطور وتفاصيلها.
- معرض منتجات تفاعلي يتحرك تلقائيًا أثناء ظهور قسم المتجر، مع دعم تقليل الحركة.
- تنقل واضح وأزرار توجه الزائر لاكتشاف المجموعة.
